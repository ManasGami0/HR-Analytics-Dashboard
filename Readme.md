# HR Analytics Dashboard

## Project Overview
This Power BI dashboard analyzes employee attrition trends and workforce insights to help organizations understand employee behavior and improve retention strategies.


## Tools Used
- Power BI
- DAX
- Excel / CSV


## Key Insights
- Sales department had the highest attrition
- Younger employees showed higher turnover rates
- Employees with lower salaries were more likely to leave
- Job role satisfaction impacted retention significantly


## Dashboard Features
- Attrition Analysis
- Department-wise Insights
- Job Role Analysis
- Employee Demographics
- KPI Cards and Visualizations
